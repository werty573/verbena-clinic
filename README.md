# Verbena Clinic: concept website

A mobile-first single-page site for **Verbena Clinic**, a fictional medical spa and clinic in Woodbrook, Port of Spain.

Concept build by **Portside Digital**: websites that work. Verbena is not a real business.

**Look:** Bodoni Moda + Pinyon Script + Figtree; teal, aqua and blush on a soft mint white, with a teal wax-seal mark.

**Scroll animation** (GSAP + ScrollTrigger + Lenis, switched off for people who prefer reduced motion):
- Seal stamps in, then a generative "thousand petals" bloom (golden-angle phyllotaxis on canvas) opens behind the hero portrait; scrolling scatters the petals
- Pill-shaped portrait opens from a slit
- Services: pinned seal dial turns 120° per pillar (Spa → Aesthetics → Medical) while the photo and service list cross-fade
- October Edit: native swipe carousel with scroll-snap and a progress bar
- Pill-shaped before/after slider that sweeps once on entry (illustrative; real client photos go here)
- Weight-management program: a curved line draws through the four steps
- Treatment finder: pick a goal, get three suggestions with prices
- Gift certificate card tilts in on scroll, with a shine sweep and an animated value
- Booking form with validation and a demo success state

**Mobile:** sticky bottom dock (call / book / WhatsApp), safe-area padding, 16px inputs, no tap highlight, hover styles gated to mouse.

Call, WhatsApp and booking actions show a demo message instead of contacting anyone.
